# textstats · 稿件字数与可读性

纯前端的稿件统计工具，部署在 GitHub Pages，所有计算在浏览器本地完成，稿件不上传。

## 功能

- **基础统计**：汉字数、字符数（含/不含空格）、英文词数、标点数
- **结构统计**：段落数、句子数、平均每句标点
- **时长估算**：默读速度、新闻播报速度可调，估算阅读与口播时长
- **长句提示**：按可调阈值标出过长的句子，便于拆分
- **重复词组**：统计 2–4 字连续汉字片段频次，发现啰嗦或口头禅

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
python -m http.server 8000
```

## 部署

推送到 `main` 分支，`.github/workflows/deploy.yml` 自动发布到 GitHub Pages。
